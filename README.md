# T01 - Modern Project Setup with uv

## Project Overview

This project demonstrates how to set up and manage a modern Python project using `uv`.

The project uses Python 3.14 and the `requests` package.

## Technologies Used

- Python 3.14
- uv
- Requests
- Virtual Environment
- TOML
- VS Code
